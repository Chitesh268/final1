ARISE — Shadow Monarch Edition

Open index.html in Chrome or Edge, or deploy the complete folder to GitHub Pages. Keep all included files together.

Audio behavior:
- alert.mp3: app-opening attempt and system alerts/notifications.
- quest.mp3: daily quest and Body Training checkbox changes.
- Ordinary button taps are silent.

Browsers may block sound until the first user interaction. If the opening sound is blocked on page load, ARISE retries on the first non-checkbox interaction. Enable System sound effects in Settings.

Performance: the aura animation uses fewer particles and shorter border paths to reduce rendering work. Progress is stored locally in this browser/device; export a backup in Settings before clearing browser data.
